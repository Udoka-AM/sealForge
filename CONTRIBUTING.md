# Contributing

1. Pick a task from [docs/06-IMPLEMENTATION-PLAN.md](docs/06-IMPLEMENTATION-PLAN.md) and open a branch `task/<id>-<short-name>`.
2. Keep changes inside that task's scope. Update the docs in the same PR if behaviour changes.
3. Run the checks listed in the README before pushing.
4. Open a PR using the template, including the privacy checklist.
5. Squash-merge to `main` after review and green CI.

By contributing you agree that your work is dual-licensed under MIT and Apache-2.0.
