Auditable sealed-bid auctions on Zcash: the clearing price is public, the bidders aren't.

These pages are written for Zcash protocol and wallet engineers first. Every technical claim cites the code (`path`, function or constant) or an evidence file. Every behaviour carries a status label from the table below. The source of every page is in [`docs/site`](https://github.com/Udoka-AM/sealForge/tree/main/docs/site) in the repository. The engineering documents in [`docs/`](https://github.com/Udoka-AM/sealForge/blob/main/docs/README.md) (PRD, TRD and the rest) are the design history these pages cite.

## Status labels

| Label | Meaning |
|---|---|
| `Mainnet` | Has run on Zcash mainnet. **Nothing has yet.** |
| `Testnet` | Has run on public Zcash testnet. The page cites the auction code and transactions |
| `Regtest` | Exercised end to end on the local Zebra + Zaino chain |
| `Tested` | Unit or integration tests only |
| `Specified` | Types or design exist, not built |
| `Not built` | Neither |

## Conventions

- Amounts are integer zatoshi (1 ZEC = 10^8 zat). "TAZ" is testnet ZEC.
- `‖` is byte concatenation. `u32 LE` and `u64 LE` are little-endian unsigned integers.
- Paths are relative to the repository root. Code citations are to `main` at the commit these pages were written against (see the [changelog](/appendix/changelog)).
- Upstream behaviour (Orchard, Ironwood, PCZT, RedPallas, note encryption, consensus) is cited to the ZIP, the protocol specification or the upstream source and version. It is not restated from memory.
