Every specification these pages cite, and what for. Titles and statuses as listed in the [ZIP index](https://zips.z.cash/) on 2026-11-13. Statuses change; check the index.

| [ZIP 312](https://zips.z.cash/zip-0312) | FROST for Spend Authorization Multisignatures (Draft) | Rerandomized FROST for the spend authorization key. **Not** cited for `nk`/`rivk` generation, which it doesn't specify | [3 §Escrow key construction](/zcash-integration#escrow-key-construction), [§Threshold signing](/zcash-integration#threshold-signing) |
| [ZIP 316](https://zips.z.cash/zip-0316) | Unified Addresses and Unified Viewing Keys | Receiver types, UFVK, UIVK | [3 §UA, UFVK, UIVK](/zcash-integration#unified-addresses-ufvk-uivk) |
